+# Interface e navegação
+
+## Limites de paridade
+
+A correção de navegação não comprova paridade integral do produto. Antes de afirmar equivalência completa, revisar continuidade de Projeto de Paper para Paper Final no mesmo projeto, gestão manual de planos/créditos, fichamentos, edição/exclusão de fontes e composição acadêmica do PDF. Não anunciar capacidades apenas porque existiam no sistema anterior. O legado é referência, nunca dependência de runtime ou banco de testes.
+
+A vitrine e as telas de conta compartilham tokens de cor, botões, campos e estados de foco em `static/css/app.css`. O CSS de marketing complementa a vitrine, mas não substitui os estilos do cabeçalho. O menu desktop deve ter espaçamento explícito; no celular, a navegação pública usa um menu recolhível.
+
+## Links e exemplos públicos
+
+Todo link ou botão anunciado na vitrine precisa ter um destino ou interação funcional. Termos, privacidade, informações sobre IA e jornada são páginas públicas. Modelos usam exclusivamente dados demonstrativos; nunca consultam contas ou projetos reais. Os arquivos Pix existentes representam pagamento manual, sem integração automática.
+
+## Conta e editor
+
+As telas internas possuem acesso direto a trabalhos, biblioteca e perfil. O aceite dos termos é obrigatório para criar um trabalho; IA e WhatsApp são escolhas independentes. A interface deve mostrar confirmação ao salvar perfil ou consentimentos e indicar claramente quando a criação exige aceite.
+
+As etapas acadêmicas são blocos recolhíveis com atalhos, evitando exibir simultaneamente todas as redações longas. Recolher uma etapa não apaga seus campos nem retira seu conteúdo do autosave. Case e Paper mostram apenas os prazos pertinentes ao roteiro escolhido. A narrativa e a Linha do Tempo permanecem recursos diferentes.
+
+O formulário acadêmico e o de compartilhamento são irmãos: formulários HTML não podem ser aninhados. O autosave serializa requisições, mantém a revisão associada à requisição e grava novamente quando houver mudanças durante a resposta. Um conflito preserva o conteúdo local e pede ação explícita; não deve sobrescrever o servidor silenciosamente.
+
+## Verificação
+
+Testes de contrato validam rotas públicas e estrutura dos formulários. Além deles, use navegador real com banco temporário para abrir a conta, criar um projeto, editar um campo e observar o estado salvo. Verifique desktop e celular, abertura do menu, exemplos e ausência de rolagem horizontal. Nenhum teste exige Google real, envio WhatsApp ou leitura do banco de produção.

+from html.parser import HTMLParser
+
+
+class FormMarkupParser(HTMLParser):
+    def __init__(self):
+        super().__init__()
+        self.forms = []
+        self._open_forms = []
+
+    def handle_starttag(self, tag, attrs):
+        if tag != "form":
+            return
+        attributes = dict(attrs)
+        form = {"attributes": attributes, "parent": self._open_forms[-1] if self._open_forms else None}
+        self.forms.append(form)
+        self._open_forms.append(form)
+
+    def handle_endtag(self, tag):
+        if tag == "form" and self._open_forms:
+            self._open_forms.pop()
+
+
+def csrf(client):
+    with client.session_transaction() as session:
+        return session["csrf_token"]
+

+    assert accepted.status_code == 302

+def test_editor_has_no_nested_forms_and_sharing_is_sibling_form(client):
+    login(client)
+    created = client.post("/projects", data={"csrf_token": csrf(client), "project_type": "case"})
+    editor = client.get(created.headers["Location"])
+    assert editor.status_code == 200
+
+    parser = FormMarkupParser()
+    body = editor.get_data(as_text=True)
+    parser.feed(body)
+
+    assert len(parser.forms) == 2
+    assert all(form["parent"] is None for form in parser.forms)
+
+    editor_form = next(form for form in parser.forms if "data-project-editor" in form["attributes"])
+    sharing_form = next(form for form in parser.forms if "data-sharing-form" in form["attributes"])
+    assert editor_form["parent"] is None

+    assert sharing_form["attributes"]["method"] == "post"
+    assert 'data-reload-editor' in body
+    assert 'aria-live="polite"' in body
