- Add configurable timeouts for AI providers (DeepSeek, Gemini, JEV) via env vars
- Add AbortController support in frontend for AI requests (project-ai.js, jev-panel.js)

- PROVIDER_TIMEOUT (default 30s) - base timeout for all providers
- DEEPSEEK_TIMEOUT (default 30s) - DeepSeek API timeout
- GEMINI_TIMEOUT (default 30s) - Gemini API timeout
- JEV_TIMEOUT (default 60s) - JEV/Typesafe API timeout
